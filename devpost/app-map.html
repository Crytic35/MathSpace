2. Three Key Code Locations

Stop 1: The Analytical Solver

src/math/planeSolver.ts → solvePlaneIntersection()

Computes normal vector cross products, checks scale-aware collinearity (σ ≤ 10⁻⁷), performs normalized-distance coincidence testing, and selects the maximum absolute 2x2 minor determinant to condition the particular point p₀.

Stop 2: The Bounded Polygon Clipper

src/math/planeClipper.ts → clipPlaneToCube()

Intersects the infinite mathematical plane against the 12 segments of the coordinate box [-10, 10]³, deduplicates coincident vertices, and orders vertices angularly around the normal vector to form a convex polygon for Three.js rendering.

Stop 3: Three.js Viewport & Depth Blending

src/viewport/viewport3d.ts → updatePlanes() and updateIntersectionLine()

Updates vertex buffers dynamically without disposing materials. Uses depthWrite: false with double-sided transparent materials so overlapping planes remain legible from any viewing angle.

3. To Change This, Start Here

  • Add a new 3D or 2D Preset: Edit src/state/presets.ts. The dropdown automatically populates and configures the camera and equation values.
  • Adjust Coordinate Boundaries: Change bound = 10 in src/math/planeClipper.ts and src/viewport/viewport3d.ts.
  • Customize Styling & Colors: Edit CSS custom properties in src/ui/styles/tokens.css.

4. A Practice to Reuse

Decouple Mathematical Computation from Graphics Rendering:

By keeping src/math/ 100% free of DOM, Three.js, and Canvas dependencies, all numerical algorithms, floating-point tolerances, and singular edge cases were verified with 21 automated unit tests running in under 500ms using Vitest before any rendering code was wired.
